#¿Que hara mi adolescente?

Esta pequeña app es para interactuar con un adolescente, haciendole preguntas y el te responde de forma aleatoria .

![imagen-menu](Captura%20de%20pantalla%202026-10-13%20180328.png)

![imagen-pregunta-respuesta](Captura%20de%20pantalla%202026-10-13%20180349.png)

Según le escribas la pregunta , en mayúscula toda, o con interrogaciones, o mitad minúscula mitad mayúscula así te responde.

Este código fue el primero que hice con javaScript y creando funciones.
